## 验证条件与结果

- 验证类别：静态 / 创建者自测 / 独立目标模型执行 / 迁移或对照。
- 计划与实际模型、思考档位、宿主及工具：
- 配置依据：请求参数 / 宿主记录 / 服务端标识 / 未核实。
- 上下文范围：允许材料、是否继承开发历史、默认记忆和共享文件的限制。
- 任务来源：开发任务或未参与修订的新任务。
- 对照：旧版 / 无 Skill / 无对照；是否同条件。
- 实际成果位置与主要判定：
- 原意保留检查：关键方法、质量、必须/默认/例外和自主空间是否仍成立？
- 核心业务效果检查：任务实际用了哪些被补判断，哪些仍未验证？维护行为与业务效果分开记录。
- 失败、重试、作者提示或人工修改：
- 自动发现/隐式触发是否经过真实宿主检查：
- 不同于原测试的最终修改及补测范围：

- 通过、部分达到、失败和未验证的范围：
- 下一步所需条件或已确定的修复：
