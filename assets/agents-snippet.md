## Skill 创建与改进

当已授权工作涉及创建 Skill、实质修改其方法或适配新执行条件时，从宿主技能目录找到 skill-improve，读取其 SKILL.md 并按当前阶段使用。任务中途进入这些工作也适用，无需用户再次点名。

创建工作由 skill-creator 等可用创建流程主导；有可读草稿后，在交付前用 Skill Improve 检查隐含方法、判断标准、必要资料和独立执行条件，落实有依据的修正。没有草稿时先创建，已有有效检查直接复用，按实质改动选择必要验证。

普通业务调用、概念讨论、纯安装和错字小修不启动完整优化。已经进入改进流程时继续当前步骤，不反复自调用或与创建工具循环互调。发现业务问题不自动扩大维护权限；对全局安装副本的写回仍须在已有授权范围内。

无法找到或读取本 Skill 时说明具体缺失，继续能完成的创建工作，不宣称已完成 Skill Improve 检查。不要为满足本规则自行安装工具、联网找包或改写全局配置。
